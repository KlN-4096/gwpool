# 网关选路研究：已验证的行为模型与不可识别边界

日期：2026-10-05。下文实验时间均为 UTC。研究目标按“实现并验证最小行为模型；不能唯一识别时给出反例、等价假说及缺失证据”交付，**不是宣称还原了官方内部算法**。

发布说明：2026-10-16轻度脱敏归档，以下结论及交付状态均对应上述研究日期。账号使用与SPEC及开发日志一致的稳定研究别名；保留网关编号、地理、样本数与失败结果。仓外源码及原始证据未随仓发布，下列文件名仅作私有材料编号，不是可公开下载链接。

## 1. 最终结论

已经实现一个预测“成功裸铸时，新 `__oailb` 声明哪个 unified 网关”的账号×出口地理统计模型。它在两批事先冻结的自然新样本上优于账号单变量基线，并在一组事先冻结预测的 US→JP→US 实验中命中 3/3。它不是任意指定网关的方法，不预测请求成功率、实际计算后端或真实模型能力，也不能预测训练中从未出现的新网关。

更细的州模型没有兑现开发期的预期优势：新全量样本只比国家模型多对 1/50；美国端点同为 12/20。因此没有将州划分、国家池、冷却时长或“满血”标签提升为上游确定规则，没有更改正式选路策略。

## 2. 可运行的最小预测模型

当时使用的仓外实现（未随仓发布）：

- 国家模型：`routing_country_transfer.py:67`
- 州候选模型：`routing_geo_model.py:28`
- 国家前瞻执行器：`evaluate_routing_future.py`
- 地理前瞻执行器：`evaluate_geo_routing_future.py`

设 d 为铸票身份域，c 为实际观测出口国家，g 为历史网关，p₀(g) 为训练集网关频率。固定伪计数 α=10，国家模型选择：

`argmax_g [(n(d,g)+αp₀(g)) × (n(c,g)+αp₀(g)) / p₀(g)]`

州模型把国家项替换为“州计数＋向国家分布收缩”的地理项；缺州或未见州回退国家模型。未知身份退化为地理排序。只从训练网关集合输出，分数未做经验概率校准，不把最高分叫“成功概率”。

逻辑流程：

```text
训练：只读取冻结的历史成功裸铸；按身份域、实际地理、网关计数
预测：只使用当次身份与出口信息，不使用当次返回网关
评估：先锁定源码/数据/时间/停止规则，再收新样本，一次揭盲
失败：保留原始尝试分母；不把无网关标签的失败算作可预测成功
输出：预测 cookie-host；能力与真实后端保持未知
```

分解公式可解释为条件独立近似，但数据没有证明该独立假设，更没有证明上游使用同样公式。对已揭盲数据的错误分析只能作为以后开发材料，不能再次作为独立盲测。

## 3. 实际验证，而非只报开发集

原冻结快照共 16,032 条 sample；有明确用途的 bare 子集 5,452 条，其中 3,923 条满足成功、身份、实际国家及网关条件。旧 70/30 开发切分为 2,746/1,177，不计作前瞻证据。

| 预先冻结的自然端点 | 国家分解模型 | 州分解主模型 | 账号基线 | 历史账号×国家查表后回退账号 |
|---|---:|---:|---:|---:|
| 第一批首 50，10-04 20:30–20:50 | 36/50 | 未参与 | 13/50 | 28/50 |
| 第二批首 50，10-05 02:15–02:48 | 35/50 | 36/50 | 8/50 | 18/50 |
| 第二批美国首 20，至 04:29 | 12/20 | 12/20 | 2/20 | 11/20 |

第一批评估期 58 次 bare 尝试：50 个合格成功、8 个 status=0。第二批首 50 的评估期为 61 次：50 个合格成功、9 个 status=0、2 个 HTTP 429。美国失败不能凭缺失的 Geo 国家强行归入美国分母；对应全国家时段保留了 367 次尝试中的 61 个非 200。

第一批包含 49 个身份域，第二批首 50 包含 50 个，US 20 包含 17 个；重复身份观测不当独立账号。第二批 all 与 US 有重叠，不能合成 70 个独立样本。美国时段还跨过另一项获授权的正式部署及 D2 实验，不能称环境恒定，也不能用前后异样本成绩推断部署因果。

州模型与国家模型在第二批首 50 中只有 3 个正确性不一致样本：州独对 2、国家独对 1；US 正确性完全相同。揭盲后的描述性分层中，US 已见身份×州格为 9/9，未见格为 3/11，两模型均如此；这不是另一个独立检验。

私有证据编号：第一批`routing-future-2058-result.json`、第二批全量`geo-routing-sixth-all.json`、第二批美国`geo-routing-sixth-us.json`、揭盲后分层`geo-routing-evaluation-descriptive-strata.json`。

## 4. 两组受控实验及它们真正排除了什么

### C：固定美国出口，切换两个账号域，ABBA

同一个代理 SID；前后 US Virginia/Ashburn、ASN、IP 标签一致，CF 边缘均 EWR。请求正文及客户端 session/thread/window/installation/PCK 等身份字段固定，无入站 cookie 或 turn-state；切换 OAuth 身份。观察：

`研究账号D→15；研究账号E→79；研究账号E→79；研究账号D→15`

四次 HTTP 200，全部落账。冻结的国家分解、历史查表、国家迁移预测都只中 **2/4**，没有删除失败预测。结果与“不依赖账号、只由所控出口和显式客户端字段确定的固定函数”不相容；但两个账号仍可能携带不同服务端隐藏状态，随机或时变路由也未被排除。它不证明账号 ID 本身就是哈希键。

### D2：固定一个账号域，US→JP→原 US

研究账号F，正文和显式客户端身份固定，出口各用自己的固定 SID，前后 Geo/trace 检查一致：

`US California / SJC→126；JP Tokyo / NRT→75；原 US→126`

三次 HTTP 200，全部落账。预测在 03:54:55 冻结，实际请求在 04:26–04:27；国家/州分解模型均 **3/3**，历史国家查表 **1/3**，账号基线 **0/3**。这与“同账号不论出口始终只有一个固定网关”不相容。

但 country/state/IP/ASN/CF 边缘/代理 SID 同时变化，不能单独归因国家；前后 IP 检查也不是模型目标连接的逐请求 source-IP 证明。一账号三次重复不等于三个独立账号，更不是任意账号保证 100%。

私有证据编号：C为`routing-study-20261005c-analysis.json`、D2为`routing-study-20261005d2-analysis.json`。研究组累计模型请求 8 发已达预设上限；另外两次 Geo 失败保留计账，未重置额度。D 预检失败无模型请求、无停服，失败记录保留。D2 恢复复核为 27.167 秒、健康检查通过、正式 binary/config 不变；这是当次验收记录，不冒充此刻实时监控。

## 5. 必须分开的三个层次

| 层次 | 现有证据允许说什么 | 不允许推出什么 |
|---|---|---|
| 新票标签分配 | 新 `__oailb.host` 有可预测的身份×地理关联；上面两组控制提供可逆变化/重复的例子 | host 就是实际计算机房；可强制任意落点 |
| cookie / turn 亲和 | 本地官方客户端快照明确 turn-state 同 turn 原样回送、新 turn 清空；库存 106 票均有 host/iss/aud/iat/exp，exp−iat=3900 秒 | 3900 秒为满血期；票明文无账号字段就代表服务端无绑定；没有新 cookie 就证明仍在原实际后端 |
| 品质调度 | 现有 state-echo 表型可统计；旧时间留出 1,997 条上，网关×请求模型的 Brier 为 0.195822，优于仅请求模型的 0.218413 | 这是独立能力标签、真实执行型号、官方恢复/CD 算法或换网关的因果收益 |

客户端依据：当时检查的私有源码快照`codex-rs/core/src/client.rs:265–292`。这是所检查源码快照的契约，不冒充服务端内部实现，也不声称该行号适用于其他版本。票结构仅解码，未独立验签；私有证据编号`oailb-structure-20261005-detail.json`。

品质观测的具体缺口：当前预热 A 返回 200 但无 state 判未知，B 返回 200 无 state 却可判 Full；业务 200 的同 state/无 state 分支也可记 Full，这些分支不读取 SSE 正文确认真实能力。不能把这里的 Full 自动翻译为“执行了指定大模型且能力完好”。这属于测量限制，本研究未顺带改动生产判据。

只读核对的历史深抓有 96 个 200 响应，未发现独立 backend/model-instance 标识；相同 declared model、faster-model 头、state 长度下既有 exact_29=86，也有 other=10。简单答案本身没有校准，faster-model 只是提示，均不能完成真实型号鉴定。私有证据编号`deep-capture-observability-summary.json`。

## 6. 明确反例，而不只列“可能存在局限”

1. **固定账号×国家查表不是确定函数。** C 中研究账号E的冻结 US 预测为169，实际两次79；同一账号历史 US 来自 Washington，而 C 为 Virginia。细地理/时间等可以解释，但国家层确定规则已不适用。
2. **固定互斥国家/州分池不能直接由支持图推出。** 旧快照中 DE/AE 共享134；California既与Washington共享119，又与Florida共享12。能否定预先把这些地区分入不同互斥池的版本；允许合池、重叠或动态支持的版本仍可解释。零观察不证明不可达。
3. **高条件命中率不是广泛可用性。** 旧开发集的国家迁移为164/174，但只覆盖174/1177；完整规则441/1177，低于国家分解552/1177。没有拿94.25%的小子集宣传整体准确率。
4. **分解模型本身有不可学习的交互。** 合成四格 `(账号0,A→1),(账号0,B→2),(账号1,A→2),(账号1,B→1)` 的所有单变量边际相同。调用现有国家/州模型实测：每格1条或100条，均只中2/4；精确查表能记住4/4已见格，但不证明未见格迁移。此为模型容量反例，不是伪装成真实上游样本。私有证据编号`routing-identifiability-witness.json`。

## 7. 剩余等价机制与能区分它们的证据

以下是明确的候选构造，不是对官方实现的断言。

- **哈希分配与显式查表：** `g=π(z)(h(account))` 可以由 `T[account,z]` 查表实现相同输出。即使所有可见组合都预测正确，也不能仅凭输出识别内部采用哈希还是表，更不能识别哈希函数。需要服务端决策键、映射版本/trace；外部实验至多继续缩小可见行为类。
- **账号键与账号相关隐藏状态：** 身份相关的 entitlement/cohort/session 键可以替代直接 account ID，产生相同 ABBA。C 已固定显式客户端身份，不能再归咎“忘了固定 session-id”；仍缺服务端状态观测。要隔离可控会话因素，需账号×独立客户端 session/PCK 的交叉随机干预，同时控制/记录出口、时间、cookie 状态；即便无效，也不能排除未操纵的服务端状态。
- **逻辑入口即 compute，与入口后再分发：** 两者可以返回完全相同的 `oailb.host` 和 state。需要每个请求 ID 对应的可信执行集群、部署/模型版本遥测，或有服务端保证的路由 receipt。CF colo、DNS Geo、响应 model 自述不能替代。
- **真实能力变化导致 state 刷新，与纯亲和更新导致刷新：** 两者都能解释当前 Full/refreshed 标签，因为标签本身就从 state 得来。需要不依赖该头部的盲评能力测量、错误/完成事件及真实模型遥测；单题、重复同一个 echo 或增加同类接触记录不解决循环标签问题。
- **国家因果与其他出口因果：** D2 的地理、IP、ASN、边缘、SID 共变。需可重叠地理/供应商条件的随机交叉设计，并取得目标连接实际出口证据；前后 ipinfo/trace 一致仍不能完全观测中间目标连接。

现有 contact 快照还存在按窗口更新覆盖、历史裁剪和不完整逐请求关联，不能重建全部真实接触/恢复曲线。因而“账号冷却独立还是 workspace 共用”“真实最短恢复时间”“票 TTL 是否等于品质期”均没有在本研究中证明。没有恢复之前已取消的冷却/寿命实验。
