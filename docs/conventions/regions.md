# 探索出口与覆盖目标

- `config.Regions` 是可热重载的实际出口定义，缺省九区，上限256；稳定key与国家/州/城市不可改或删除，名称/启用态可改，停用不重置历史/配额。全球扩展追加各目录并集的缺失国家，保留已有启停与显式空分组，幂等且不立即探测。
- `RegionDefinitions` 供历史/视图，默认列表独立可变；`RegionByKey/RegionKeyOf`缺省时直接查默认值，不为单值查询分配整表，显式空列表不回退默认、停用项仍供历史反查。`CandidateRegions`仅含启用项；所有消费读配置，不热改`types.Regions`全局变量，增区不扩大并发。
- `CoverageGroups` 另存显示名、实际出口关联、显式目标网关和“清单完整”确认，不因分组改名修改种子或限额。
- `internal/coverage` 内置 2026-10-01 DNS 枚举得到的 201 名（最大编号215，有跳号），只是历史可解析候选；禁止当成当前可铸全集或按 IP 地理归类。
- 分组“已找满此清单”要求：非空、确认完整、每个目标均存在与关联出口匹配的历史 `ReachableExits`。票过期不抹掉历史；未知归属单列。
- 原始候选+实际发现+手填目标合并展示，当前可交付只按有效票寿命，不代表任意账号的冷却/配额资格。
- 专门探索优先未完成区的未走组合，每自然轮最多一发；已完成区不争这份预算，但续票/补库存仍可使用。所有明确目标完成并不代表未知目录也完成。
- `/admin/coverage` 写入口需 admin+sameOrigin，64KiB 表单限制；配置只按键 Patch，不能序列化整份含 Secret 的 Config。保存不立即探测。
- 回归：`config/regions_test.go`、`coverage/coverage_test.go`、`sched/{regions,explore}_test.go`、`mint/regions_test.go`、`httpapi/coverage_test.go`、`cmd/gwpool/discovery_test.go`。
- 实际出口含country/state/city，逐供应商校验能力，不支持不得静默忽略；只有Geo有全部匹配证据才新增实际可达关系，seed续票不制造地理证据。
- 增区不放大独立账号总预算（默认滚动1h50次、国家2次）；目录候选还要与`geography.Supported`交集，HK/AQ等拒绝尝试但不删除历史定义。静态seed只续旧票，动态供应商用于新铸/库存/探索，共用账号锁和预算。
- Novproxy207、Webshare249代码来自用户菜单属性，Cliproxy去重203（重复MD取首条，MG独立存在）；并集249，能力按供应商过滤，不能把一家的目录泛化给另一家。Ipipgo未提供完整独立目录，仍按已有协议和实测落地判定。
- 自然专门探索游标按尝试推进而非仅成功；绑定/铸票失败也让后续国家获得机会，小时预算不重置游标，进程重启会重建。每轮仍至多一发，未满实际出口优先；低收益退避不变。
- `coverage/datacenters.json`是2026-10-01 DNS/IP表201行的机房地域元数据（22国/39国家×城市），只用于独立的历史目录分母；未知新增网关不凑入分母，票过期不抹掉历史完成，不据机房地域反推出口全集。
- 公共池按已发现网关的机房归属分九区（未知单列），不公开201分母/缺失名称/完成率；与管理机房分区一致，每个网关只计一格。账号/Owner仍按其实际探索出口九区展示历史证据，原国家/出口key留后台记录与覆盖编辑器。
- 范围打票只选九区，区内每个支持国家取一个原出口（国家级优先城市）；默认不选，须显式预览→确认。持久尝试较少国家先走，失败也推进，50次总预算不让固定前50国长期垄断。
- cflb是服务端亲和值，不是可公开解码的权威大区ID；相同/不同文本均不足以证明地理或路由等价。九展示区、实际出口key、上游路由类、201机房目录必须分开。
- 截至2026-10-04研究，106是已发现数量，不是代码或已证明的上游上限；点名API是取现成票/历史路线预测恢复，不是无票直接命令上游分配任意unified-N。
