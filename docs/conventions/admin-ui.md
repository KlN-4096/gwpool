# 页面、权限与清理

- 页面门禁（site_key）、上传者/单账号令牌、管理员登录是独立权限；`base.Admin`只在完成管理员鉴权的handler赋值。管理员浏览器走`/admin/login`的Passkey/密钥及30天可撤销Cookie，非浏览器脚本保留Basic/Bearer；浏览器缓存Basic不能绕过退出。
- `admin_auth.go/admin_passkey.go`固定配置origin/RP、必需用户验证、5分钟一次性挑战与新增/移除前新鲜验证；会话仅存摘要，退出/过期/删除关联Passkey/管理员密钥或公共地址变化均失效。只在持久提交成功后发Cookie。
- 认证读体限64KiB/10秒，必须在认证锁外；挑战消费/校验/提交与退出同锁，CeremonyHash撤销迟到登录。反代限流仅显式信任loopback且Caddy覆盖的单IP X-Real-IP；管理员页Referrer-Policy保留同源表单Origin，不能放宽接受Origin:null。
- `/admin/keys`只用管理员鉴权；账号Key(upload，默认)/凭证Key(legacy，旧版兼容)/管理员生成Key(admin)三个互斥页签，统计和搜索/分页/详情都按来源隔离，无全部混合列表；生成入口与独立限额列仅admin可见。
- 仅upload列表/详情显示上传账号数：按当前OwnerID计现存账号，含停用/过期，已删不计、重传不重复；与HTTP account摘要数分离。数量链接复用`/u/{token}`→`/a/{view_token}`，来源已移除不造死链，不加Key抽屉拦截属性；回归`keys_accounts_test.go`。
- 同源POST批量先校验全部ID同来源，显式来源不匹配/跨类拒绝后才调用原子更新；缺source旧表单只允许推导单一来源，旧详情链接按KeyID推导。返回链接保分类和筛选，生成结果固定admin；撤销需确认且不可恢复，不影响上传凭据本身。
- Key主屏只放紧凑统计/筛选/列表，生成与一次性结果用dialog、详情/编辑用右侧drawer；未选中隐藏批量条，撤销确认冻结本页所选ID。无JS/无dialog保留原生表单与详情链接；专属控件不交给layout通用`data-js`显示。
- 详情只GET原鉴权页面，abort＋版本号拒迟到响应，关闭恢复焦点；列表/分页URL去掉`key`以免重开已关闭详情。页级表格显式覆盖通用1%列宽；屏幕阅读器隐藏标签需固定绝对位置，不能从横向表格泄出页面宽度。
- Key列表/详情仅“最后请求”用RFC3339 UTC元数据在浏览器按当前时区转换，显示IANA时区；动态详情插入前同样转换。空时间不造日期，Intl不可用/坏时间/无JS保UTC回退；创建时间、小时桶、存储与排序不跟随转换。
- `gwp_k_`独立Key仅消费、必须提供外部account，走`DeliverAnonymous(authed=true)`且不授后台登录/托管归还/续期权限；管理员生成的普通Key独立RPM/并发，上传者与legacy永不进入该限流，公共Key保持原共享规则。
- AdminKey只在管理员生成表单显式选择，以`Source=admin && AdminKey`判权；免Key/成员消费限额及公共开放门槛/排队，直接准入但不抢占库存。类型创建后不可编辑，普通限额0、配置root Key或请求参数不能升级；统计/停用/撤销及输入/有效票校验不变。
- 新Key仅生成响应展示，按一行一个复制/下载txt；生成表单签名载荷的摘要作为持久防重ID，不能hash可大小写变体的签名文本。列表只显尾号，不从摘要恢复密钥。
- 统计是已注册机器API的HTTP计数，不是模型/满血率；票数只计完整响应写入成功，不保证客户端收到。60s/5min秒桶和在途重启清空；累计/168小时桶每30s及正常关闭保存，失败和统计容量不足可见，统计容量不得改变消费准入。
- 公共Key由根消费密钥分域派生，开关开启即在公开接入区显示（未达门槛也可预存），关闭不显示；URL只读配置。首页/Owner/凭据页共用`integration-guide.html`端点速查表，仅列用法/参数/限制及必要身份说明，不扩成长教程；机器API保留原Sub2api升级提示。身份约定和基本格式校验须区分，命令行含`&`的URL须加引号。
- 机器API统一鉴权；无Key/错误Key始终401，不能靠匿名回落绕过公共限额。公共身份不借传入托管账号ID获得凭据权限；退役归还/续期接口仅426。`/contact/reports`与对应单条使用同一准入/保存语义，批量一次HTTP准入，单项错误不丢其它项。
- 公共限额默认全体共享720次/滚动分钟、并发10、排队50、最长1s，令牌桶突发容量等于并发上限；FIFO取消/超时清理、不计未准入请求。普通Key不入公共队列；热修改不撤销在途，重启清空准入计数。
- 公共限流返回503/rate_limited和Retry-After，出队复查开放门槛；这是池端保护，不保证现有客户端自动退避。一个公共Key只占一个reporter域，个人报告仍按账号tag隔离，不能伪造50个独立消费者票数。
- 管理sidebar与201历史机房目录仅管理view持有；公共`poolRegionCells`只对已发现名称查询机房归属（同后台），不遍历候选目录，不下发分母/缺项。九区+未知互斥合计等于全池，未知不从代理出口推断；紧凑网关格保留。
- `buildDirectory`只汇总Snapshot.Datacenters，目录外另列Unknown；不使用含目录外发现的Snapshot.Found当201分子。零分母显示暂无条目，不报100%。
- 公共网关无Cookie/账号来源/消费明细；公开动态用poolMintRow白名单。单账号页面只在owner cookie匹配时给总览链接；gate不含运行模式/业务导航/原始私密URL。
- `acards`和`gateway-cards`仍保留语义表格、搜索/排序/24条分页；详细观察放dialog或原生details，无JS不丢数据。
- Owner默认折叠卡片；`gwpool.expanded.v2`显式记展开集合，旧折叠集合不推断为“全部展开”。窄屏说明不放进nowrap按钮。
- 账号近15分钟统计在截断500条展示前按ID、时间窗计算；HTTP200不是交付/质量成功率，耗时中位数仅含正耗时样本。
- 401清理：只认当前禁用、有AT、mint/scan固定401前缀。GET签名候选/10分钟TTL→同源管理员POST确认→Store账号锁升序→写锁复核→一次DropAccounts WAL提交。
- 确认绑定CredentialRevision及凭据指纹；启停/重传/刷新/自动停用写入修订号，失败回滚。原始字段相同也不能绕过“恢复后再次401”的ABA防护。
- 删除保留Pairs/Gateways/历史；清理Slots/Mints失败须恢复内存。只处理确认候选，不把后来出现的401扩入；重复提交已删项跳过。
- 删除不能只等待在途任务：扫描每次attempt在账号锁内重读存在/启用/凭据，防排队旧快照在删除后出站或复活记录。
- 回归：`types/account_cleanup_test.go`、`store/account_cleanup_test.go`、`scan/cleanup_test.go`、`httpapi/{account_cleanup,directory,account_activity}_test.go`；`TestDashboardSettingsFixture`可导出8种假数据页面。
