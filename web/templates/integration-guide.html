统一鉴权：Authorization: Bearer <接入Key>；反馈正文使用 Content-Type: application/json。

account 填实际用票成员 OAuth 凭据中的 chatgpt_account_id/chatgpt_user_id（两值用 / 拼接），不是本地编号或 Key。同一成员保持稳定；非空、≤128字节、无控制字符，池端只校验格式。命令行直接拼接含 & 的 URL 时，整个 URL 必须加引号。

端点用法限制
GET /gateways 查网关目录；必填 account。可选 model 获取模型统计、X-Gwpool-Account-Tag 请求头获取个人统计。 只返回元数据，不含 Cookie；建议缓存≤30秒并按票期缩短，个人统计按 Key/tag 隔离。
GET /cookie 点名取票；必填 account、gateway。可选 min_remaining（默认300秒，整数钳至30–3600）、exclude/exclude_versions（逗号分隔，各≤64项）。 仅交付现票，不代选、不等待、不现场铸票。force/wait/count 一律400。同成员跨 Key 共享12次/秒、444次/分钟，成功与缺票均计数。
POST /contact/report 上报接触结果；JSON 含 id/account_tag/gateway/model/criterion/source/first/at/outcome。outcome 为 full/refreshed/unknown。 ≤4096字节；每轮接触一次，时间为近7天至未来5分钟。仅 full 可用原 ID 补报结束窗口；管理员/root 不能上报。
POST /cooldown/report 上报静置验证；JSON 含 id/account_tag/gateway/window_seconds/elapsed_seconds/result，可选 observed_at。result 为 full/degraded。 ≤2048字节；计划静置3600–86400秒，实际间隔≥计划减60秒且≤604800秒。
POST /contact/reports 批量接触反馈：{"reports":[单条对象,…]}。 1–32条、整批≤64KiB、单项≤4096字节；检查 results 每项的 id/status，外层200不代表全部成功。
POST /cooldown/reports 批量冷却反馈：{"reports":[单条对象,…]}。 1–32条、整批≤64KiB、单项≤2048字节；同样按逐项结果重试。
POST /release旧归还接口，已停用。返回426 upgrade_required，保留原升级提示。
POST /pair/renew旧续期接口，已停用。返回426 upgrade_required，保留原升级提示。

用票：返回的 cookie 原样放入上游 Cookie 头，上游仍使用自己的凭据；遵守票期，取票成功不保证模型品质。

反馈：id/account_tag 均为64位hex，tag按成员保持稳定，gateway须已知；重试保留原ID、时间与载荷。拒绝未知字段；批内重复ID、非法外层或整批超限会整批拒绝，其余按单项结果处理。

错误与限额：400修参数，401检查Key，409核对事件冲突，缺票503刷新目录后退避；限流遵守 Retry-After。所有接口另受适用的Key限额与公共开放门槛约束。
